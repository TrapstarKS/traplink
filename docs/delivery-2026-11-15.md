# Test delivery, 2026-11-15 (archived summary)

Historical note; superseded by later releases.

- **Deployment.** Authentication published at `https://traplink.traphub.xyz` behind a dedicated Nginx vhost with Let's Encrypt, listening only on `127.0.0.1:3801`. Other sites on the host were verified unchanged by config hash. Nine public HTTP checks passed (health, unauthenticated rejection, recovery disabled, two isolated accounts, explicit device authorization, device isolation, per-account opaque backup, foreign-origin rejection, revocation); temporary accounts were deleted.
- **App.** Unsigned Windows test build. Device inventory reduced from 33 raw HID interfaces to physical keyboard/mouse groups. Fixed: invitation cancel/expiry, abandoned partial transfers, replaced sessions, login cancellation, input release on close, duplicate clicks, state refresh and preference drafts. Web forms gained accessible validation and session/sign-out error handling. Pairing moved to a single `traplink:v1:` invitation (addresses, temporary key, receiver identity).
- **Validation.** 44 Rust tests, 8 web tests and the 9 public checks passed; desktop and web builds passed.
- **Open at the time.** Final visual review (390 px, light mode), macOS build/hardware validation, and pairing/transfer between two physical computers. Edge switching, automatic clipboard, Internet relay and full Options+ peripheral support were out of scope.
