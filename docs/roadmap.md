# Product roadmap

## Local foundation

Per-installation identity, confirmed pairing, per-peer permissions, clipboard and file sending, profiles and local backups. None of these require an account.

## Universal Flow

Explicit focused control with key release on failure; then per-platform global capture, edge switching, monitor layout and protection against accidental switching in games. Test Windows↔Windows, Windows↔macOS, different keyboard layouts, sleep and network loss. Secure desktops/UAC and macOS permissions have their own limits.

## Peripheral adapters

HID discovery, battery and a real capability catalog. Add controls first for a physical model available for testing. Fn, lighting, special keys, onboard profiles and physical Easy-Switch vary by device. Importing from Options+ needs dedicated research, not file renaming.

## Online

Optional authentication and private backups. Next: peer signaling, direct cross-network connection attempts, an authenticated relay with quotas and end-to-end encryption. A shared account does not imply automatic remote authorization. Do not send clipboard to every computer on the account by default.

## Distribution

Security and load testing, signed Windows builds, macOS notarization, signed updates, privacy information and a support/account-deletion process before public release.
